## 📚 Overview

This directory contains hands‑on labs for the **Machine Learning** course (Semester 6). The labs cover core concepts such as supervised learning, regression, classification, model evaluation, and deep learning fundamentals. Each sub‑folder provides datasets, Jupyter notebooks, and reference material to help you experiment and build reproducible ML pipelines.

---

## 🚀 Getting Started
1. **Install the environment** – we recommend using Anaconda:
   ```bash
   conda env create -f environment.yml   # contains pandas, numpy, scikit‑learn, tensorflow, etc.
   conda activate ml-lab
   ```
2. Open any lab folder and launch the notebook:
   ```bash
   jupyter notebook
   ```
3. Follow the step‑by‑step instructions in the notebook to run experiments and modify the code.
