## Explanation of Results

### Impact of Learning Rate:
- **Higher Learning Rate (0.001)**: The parameters converge to larger magnitudes, resulting in more extreme probabilities (very close to 0 or 1). This creates sharper decision boundaries.
- **Lower Learning Rate (0.00001)**: The parameters converge to smaller magnitudes, resulting in more moderate probabilities. The model is more conservative in its predictions, with probabilities spread more across the range [0, 1].

### Key Observations:
- **Observation 6**: With alpha=0.001, probability is 1.0 (very confident class 1). With alpha=0.00001, probability is 0.884677 (still confident but less extreme).
- **Observations 7, 8**: Both learning rates predict class 1, but the higher learning rate produces probabilities closer to 1.
- **Observations 1, 2, 5**: Both learning rates predict class 0, but the higher learning rate produces very small probabilities, while the lower learning rate produces more moderate probabilities around 0.22-0.32.

## Conclusion
The learning rate significantly affects how aggressively the model updates its parameters during training. A higher learning rate (0.001) results in larger parameter updates and more extreme predictions, while a lower learning rate (0.00001) results in smaller parameter updates and more moderate predictions. Both models correctly classify the observations, but with different confidence levels.
